Release Notes, Known Issues & Beta Deployment Actions (Reference)

Release Notes: SP4K Family 1.9.28 — Service release, 30 Oct 2026

Included: ICMP 1.4.5.1; ICP-D 1.2.1.16; ICMP-XS 1.5.4. Source: R3306461_71_ReleaseNote.pdf, section 1.1 (page 1).

Additions (ICMP-XS)

  • Adds Linear Time Code (LTC) and immersive sound playback with CP850.
  • Changes the conditions for the periodic self-test; details are not specified.

Fixes (ICMP-XS)

  • Force 3D: pause and subtitles from 2D DCPs are now supported.
  • Playback/audio: fixes intermittent audio/video sync and AES67 audio glitches; improves LFE/subwoofer filtering.
  • Accessibility: fixes closed-caption issues with Sony STWA-C101.
  • HDMI: fixes occasional system unresponsiveness when switching to/from HDMI input.
  • Content: handles escaped characters in CPL signatures correctly.
  • Integration: improves stability under heavy SOAP API traffic and stops reporting failed transfers when content is already present.
  • Automation: corrects reversed behavior of InputDown input cues.

Limitations

  • ICMP-X on SP2K models: LUT-SCC 2D correction is not supported.
  • ICMP-XS: 3D test patterns follow the frame rate of the DCP being played.

Upgrade Note

  • ICMP-XS systems upgrading from 1.9.25 or earlier to 1.9.26 or later require two sequential ICMP-XS update steps. Follow InfoT-1735.
  • Default path: 1.9.25 → 1.9.26 (Force Update package required) → 1.9.28. Use the Force Update package specifically for the 1.9.25-to-1.9.28 sequence as documented.

Known Issues

  • Other 3D glitches/stutters have been discovered. Workaround: lower the multiplication frame for the RealD file to 410 microseconds.
  • Image artifact when resizing using test pattern 8. Workaround: use DCP content to resize the image.
  • The Player Repeat (Loop) option does not function and remains unresolved in version 1.9.28.
  • LTC support is available in 1.9.28, but resolution of the ScreenX synchronization issue remains unconfirmed until playback testing verifies main- and side-screen synchronization.
  • A Force Update package is required for upgrading from 1.9.24 to 1.9.25 or newer.

Beta Deployment Actions

  • Deploy to a controlled sample covering different projector, network, audio, 3D, and automation configurations.
  • Validate Eco Mode wake-up, Force 3D playback, image adjustment, content ingest/playback integrity, scheduler behavior, notifications, and iPad UI performance.
  • Capture diagnostic packages and configuration details for any failure, then escalate undocumented behavior to the Digital Testing Team and Barco Support.
  • Review beta results before approving broader production deployment.
  • Validate LTC / ScreenX synchronization by playing ScreenX test content with LTC enabled and checking main- and side-screen synchronization throughout playback; record whether the previously reported issue is resolved @ site 1154.
  • Compare resizing, cropping, and scaling with test pattern 8 versus DCP content; document any artifacts or flickering and validate the DCP-content workaround.
  • Before each deployment, record the installed starting firmware, confirm the applicable update sequence and Force Update package requirements, and verify successful startup and operation after each required step.
